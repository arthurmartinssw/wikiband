Sobre a Wikiband

A Wikiband é um buscador musical criado para ajudar pessoas a encontrarem bandas e artistas de forma simples, rápida e visual. A ideia é transformar a curiosidade musical em experiência: pesquisar, descobrir, favoritar e navegar entre artistas como se cada busca abrisse uma pequena porta para outro universo sonoro. O projeto foi desenvolvido com HTML, CSS e JavaScript, usando busca real na internet para mostrar resultados dinâmicos sem precisar cadastrar cada banda manualmente. Mais do que um site, a Wikiband quer ser um mapa para quem ama música. Procure bandas e artistas, vai que algum te interesse e te leve para outro universo?
